# Growth Without Profit — technical proof mapping

## What is demonstrated

The browser prototype shows a traceable business-decision experience:

`mock source records → deterministic metrics → structured evidence → simulated AI interpretation → options → human decision → review`

The UI uses the same figures as `examples/ecommerce/growth-without-profit/growth_fixture.json`.

## Architecture mapping

| Proposed capability | Growth demonstration | Status |
|---|---|---|
| Business Context & Data | Campaign, metric definitions, current $50 threshold, source records | Implemented as static browser data |
| Analytics & Intelligence | Revenue, orders, discount, CAC, contribution-margin calculations | Implemented deterministically in the prototype |
| AI Tools & Knowledge | Requested data, decision memory, professional methodology, structured interpret contract | Simulated; no live model/tool/retrieval call |
| Decision & Execution | AI recommends the intervention type; human selects $65 and guardrails | Implemented browser interaction |
| Review & Learning | Outcome review and decision-memory framing | Implemented static scenario state |

## Deliberate non-claims

- No LLM, API, RAG pipeline, external data connector, or database is called.
- The supplied decision history is relevant organizational experience, not causal proof.
- This is a minimal solution-design proof, not a generic agent framework or production evaluation system.
